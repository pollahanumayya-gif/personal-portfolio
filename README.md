# Alex Morgan | Student Portfolio

A responsive HTML and CSS website project.

## Run locally
Open `index.html` in a browser.

## Files
- `index.html` — webpage structure and content
- `style.css` — layout, colors, typography and responsive styles

## Customize before submission
- Replace the sample names, email addresses, descriptions and links with your own details.
- Check every link and test the page on desktop and mobile.
- Add your own GitHub repository URL after uploading.
